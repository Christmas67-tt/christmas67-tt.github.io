Privacy Policy

Last updated: November 8, 2026

HistoryFactory ("the app") is a private tool used by the owner of a single YouTube channel to upload that owner's own videos. This policy explains what Google user data the app accesses and how it is handled.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the app accesses

With the account holder's consent, the app requests two OAuth scopes:

  • youtube.upload — to upload videos, titles, descriptions and tags to the authorized channel;
  • youtube.readonly — to read the channel's ID, title and basic statistics, so the app can confirm it is connected to the right channel.

The app does not access Gmail, contacts, files, payment information or any other Google data.

How data is used

Data is used only to upload the owner's videos and to confirm which channel is connected. It is not used for advertising, profiling or any other purpose, and it is not sold.

Storage

The OAuth access token is stored only on the owner's own computer, in a local file. A local log keeps the ID, title and upload time of each uploaded video. Nothing is stored on any server operated by HistoryFactory — the app has none.

Sharing

Google user data is not shared with, transferred to or disclosed to any third party. The only service the app sends data to is Google itself, through the YouTube Data API.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page. Deleting the local token file removes all stored credentials. Uploaded videos can be deleted in YouTube Studio.
